===================================================================

HOW TO REPLACE PHOTOS
1. Open the "images" folder.
2. Replace any file with your HD photo using the SAME file name
   (e.g. save your new cover photo as p01-1.jpg).
3. Open brochure.html in Google Chrome to preview.
   Photos crop automatically to fit their box — no resizing needed.

Tip: keep the .jpg extension. If your photo is a .png, either convert it
to .jpg, or open brochure.html in a text editor and change the file name.

HOW TO EDIT TEXT
Open brochure.html in any text editor (VS Code, Notepad++).
Every page is marked with a comment like  <!-- ===== 05 WINDOWS & DOORS ===== -->
Change the words between the tags and save. Do not delete the tags.

Page 11 placeholders to fill: "Year to be added", "Licence number to be added",
and the six "Client / Project name" boxes.

HOW TO EXPORT THE PRINT PDF
1. Open brochure.html in Google Chrome.
2. Press Ctrl+P (Cmd+P on Mac).
3. Destination: Save as PDF
   Paper size: A4
   Margins: None
   Options: tick "Background graphics"
4. Save. You get the full 12-page A4 PDF.

Keep the folders (images, fonts, assets) next to brochure.html — the file needs them.
